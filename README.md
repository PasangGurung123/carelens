# CareLens

AI-Powered Healthcare Analytics Platform.

CareLens is a production-style full-stack application designed to demonstrate modern backend development, frontend development, data engineering, cloud deployment, security, and AI-assisted application development.

## Technology Stack

- Python / FastAPI
- React / TypeScript
- PostgreSQL
- Firestore
- Firebase Authentication
- Docker
- Google Cloud Platform
- GitHub Actions

## Architecture

The application consists of:

- React frontend
- FastAPI backend
- PostgreSQL analytical database
- Python ETL pipeline
- Firestore
- Firebase Authentication
- Google Cloud infrastructure
- AI analytics assistant
